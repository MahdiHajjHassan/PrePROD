## Frontend/next-owner contract

Read docs/api/auth.md. AccountDTO and Actor types contain no password hash or raw
session token. Registration does not auto-login. Browser requests use same-origin
HTTPS; the session is HttpOnly. Password change clears all sessions and requires
login again. Display-name changes accept only displayName; user/role IDs cannot
be supplied. Honor 429 Retry-After and translate stable error codes/field codes.

Own account operations are grouped in AuthService; the separate admin UserService
is introduced by M04. Global getServices composes the current auth service.
Mahdi M03 adds task writes; Joseph J02 adds forms after J01 components are available.

Deployment uses --force-recreate to reload mounted Caddy configuration, retaining
named DB/CA volumes. Rebuilds never reset existing credentials. The final repo
is not configured, so no bundle is READY or DELIVERED there.
