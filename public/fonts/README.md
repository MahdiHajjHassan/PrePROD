# Readex Pro

Readex Pro variable font (Latin and Arabic), by Thomas Jockin, Nadine Chahine,
and the Readex Pro Project Authors. Distributed under the SIL Open Font License
1.1 in `OFL.txt`.

Retrieved 2026-10-29 from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/readexpro

Original asset: `ReadexPro[HEXP,wght].ttf`. Self-hosted as `readex-pro.ttf`;
no third-party font request is made at runtime.

## Instrument Serif

Instrument Serif Regular is used for Latin display headings. Self-hosted as
`instrument-serif.ttf`, with Readex Pro as the Arabic fallback. Distributed under
the SIL Open Font License 1.1 in `InstrumentSerif-OFL.txt`.

Retrieved 2026-10-30 from https://github.com/google/fonts/tree/main/ofl/instrumentserif.
No external runtime font requests.
